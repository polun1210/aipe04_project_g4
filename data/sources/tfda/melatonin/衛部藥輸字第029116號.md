# 泰豪眠長效錠2毫克(褪黑激素)

# Circadin® 2 mg Prolonged-release Tablets

衛部藥輸字 第 029116 號

須由醫師處方使用

版本 日 期 2026-03-30

## 1 性狀

## 1.1 有效成分及含量

本品的褪黑激素活性成分非來自植物或動物。

Circadin 2mg Prolonged-release Tablets主成分為:Melatonin。

化學名稱為:Chemical name: N-[2-(5-Methoxyindol-3-yl)ethyl] acetamide。

Melatonin為略帶灰白色，無味的結晶粉末，微溶於水和稀釋的鹽酸。分子結構式為:

![Image block](doc:376ea52/tier:standard/page:1/block:14)

分子式為 $\mathsf { C } _ { 1 3 } \mathsf { H } _ { 1 6 } \mathsf { N } _ { 2 } \mathsf { O } _ { 2 }$ ，分子量為232.27。

## 1.2 賦形劑

Ammonio methacrylate copolymer、calcium hydrogen phosphate dihydrate、lactose monohydrate、silica, colloidal anhydrous、talcum及magnesium stearate。

## 1.3 劑型

長效錠。

## 1.4 藥品外觀

白色到乳白色、圓形、雙凸面之錠劑。

## 2 適應症

單獨使用於 55 歲以上睡眠品質差的原發性失眠病人的短期治療。

## 3 用法及用量

## 3.1 用法用量

建議劑量為每⽇2 mg，飯後，睡前1-2⼩時服⽤。治療最多13週。建議整顆吞服，不建議壓碎或剝半使⽤。

<u>兒童與青少年:</u>

由於安全性和有效性數據不⾜，本品不推薦使⽤於 18 歲以下的兒童和青少年。<u>腎功能不全:</u>

尚未知各個階段的腎功能不全對褪黑激素藥物動力學的影響。此類病人給予褪黑激素時應慎重。

<u>肝功能不全:</u>

尚未有Circadin使用在肝功能不全病人的經驗。根據公開資料顯示肝功能不全病人，因為清除率降低，白天的內因性褪黑激素值明顯較高，因此不推薦此類病人使用。

## 7 交互作用

## 藥物動力學的交互作用

**肝臟酵素**-體外試驗已發現褪黑激素在高於治療濃度下會誘導CYP3A，但與臨床的相關性仍未知。如果發生酵素誘導，併用藥物的血漿濃度會減少。

在高於治療濃度下，褪黑激素在體外似乎不會誘導CYP1A酶。因此，透過褪黑激素誘導CYP1A酶，進而與其他活性物質產生交互作用的可能應不明顯。

褪黑激素主要透過CYP1A酶進行代謝。因此，其他活性物質若是對CYP1A酶的作用結果產生影響，則褪黑激素與其他活性物質之間的交互作用是可能的:

**喹諾酮類**-CYP1A2抑制劑如喹諾酮類可能會導致褪⿊激素之暴露量增加。

**Carbamazepine and rifampicin** - CYP1A2誘導劑如Carbamazepine和rifampicin都可能導致⾎漿中褪⿊激素濃度降低。

**Fluvoxamine**-病人使用Fluvoxamine治療時注意，他會抑制肝細胞色素P450（CYP） 同功酶CYP1A2和CYP2C19的代謝，使得了褪黑激素濃度提高（AUC升高17倍，血清 $c _ { \mathsf { m a x } } \mathrm { i }$ 升高了12倍）。應避免併用。

**5-或8-甲氧基補骨脂素**（5- or 8-methoxypsoralen）- 5-或8-甲氧基補骨脂素（5和8- MOP）會抑制褪黑激素之代謝進而增加褪黑激素濃度，所以必須注意使用。

**Cimetidine**-Circadin和Cimetidine併⽤時，Cimetidine暴露量不變下，褪⿊激素暴露量增加1.7倍。Cimetidine會抑制CYP2D，進⽽抑制褪⿊激素代謝增加其⾎漿濃度，所以病⼈也使⽤ Cimetidine製劑時應審慎注意。

**吸菸**-由於CYP1A2的誘導，吸煙可能會降低褪黑激素濃度。

**雌激素**-使用雌激素（例如避孕藥或激素替代療法）的病人必須小心謹慎，雌激素會藉由抑制CYP1A1和CYP1A2對於褪黑激素的代謝而增加褪黑激素濃度。

**其他**-在文獻中有大量關於腎上腺素活化劑/拮抗劑，鴉片劑活化劑/拮抗劑，抗抑鬱藥物，前列腺素抑制劑，苯並二氮雜，色氨酸和酒精對內源性褪黑激素分泌的影響的數據。這些活性物質是否干擾Circadin的動態或動力學效應，或被褪黑激素影響，尚未得到研究。

## 藥效學上的相互作用

**酒精**-飲酒時不要服用本品，因為它可以降低本品幫助睡眠的有效力。本品的延長釋放特性可能被酒精改變，導致褪黑激素立即大量釋放。

**安眠藥**-Circadin可以增強苯二氮卓類藥物和非苯二氮卓安眠藥物的鎮靜性能，如zalepon、zolpidem和zopiclone。在臨床試驗中，同時投予Circadin和zolpidem後1小時，兩者間有明顯的短暫性藥效學上的相互作用。同時投予Circadin和zolpidem與單獨使用zolpidem相比，注意力不足，記憶障礙和行動失調性會提高。

**Thioridazine and imipramine**-研究顯示，Circadin與會影響中樞神經系統的活性物質如thioridazine和imipramine併服，無臨床證據顯示有明顯的藥物動力學上的交互作用。然而，與單獨使用imipramine相比，Circadin與imipramine併服，會提高病人的寧靜感，並會增加執行工作的困難度；而與單獨使用tothioridazine相比，Circadin與tothioridazine併服，會增加病人對於“眩暈”的感覺。

## 10 藥理特性

屬於Melatonin Receptor A受體活化劑，ATC code為:N05CH01。

褪⿊激素是由松果體產⽣的天然存在的激素，在結構上與⾎清素有關。⽣理上，天⿊後不久褪⿊激素分泌就會增加，約在清晨2-4點達到頂峰，並在下半夜減少。褪⿊激素是⼀種調節⽣物鐘的激素，它也與睡眠調節作⽤有關，可助眠。

## 10.1 作用機轉

Melatonin對MT1MT2受體的活性，被認為有助於它調理生理時鐘和助眠的功效。MT1受體被認為會抑制神經元放電，⽽MT2受體則和相位差有關。

## 10.2 藥效藥理特性

由於褪⿊激素可調節⽣物時鐘的作⽤以及增加內源性褪⿊激素⽣成，可有效改善睡眠質量，特別是對55歲以上患有原發性失眠的患者。

## 10.3 臨床前安全性資料

## 11 藥物動力學特性

Circadin的⽣物可⽤率數據顯⽰，成⼈可完全吸收⼝服褪⿊激素，但老年⼈可能降⾄ 50%。褪⿊激素在2-8毫克的藥物動⼒學範圍內呈線性。

Circadin的絕對⽣物利⽤率評估約15%，有顯著地首渡代謝效應，推估之首度代謝效應約為85%。在與食物並服後後2.6小時達到T<sub>max</sub>，Circadin的代謝吸收率會受食物影響。空腹和與食物並服的T $i _ { \mathrm { m a x } }$ 比較為1.6小時比2.6小時，AUC數值則不受食物影響。

## 分佈

褪黑激素的體外血漿蛋白的結合率約60%，主要是和白蛋白，ɑ1-酸性蛋白醣，高密度脂蛋白結合。和其他⾎清蛋⽩結合並不明顯。⾎清中的褪⿊激素和研究發表的濃度範圍相同，褪⿊激素分佈在所有體液中，並且在所有組織均可發現。

## 代謝

實驗數據發現，細胞色素P450系統的同工酶CYP1A1和CYP1A2，CYP2C19也可能參與褪黑激素代謝。主要的代謝物是6-硫代褪黑激素（6-S-MT），它是無活性的。在肝臟進行生物轉化。服用後12小時，代謝物完全排泄。

## 排泄

半衰期為3.5-4小時。代謝物由腎臟排除，以89%的硫酸化和6-羥基激素的葡糖苷酸綴合物，以及2%的無代謝原型排泄。

## 性別

女性的最高血中濃度 $( \mathsf { C } _ { \mathsf { m a x } } )$ 比男性增加3-4倍。甚⾄同性別的不同個體的最高血中濃度$( \mathsf { C } _ { \mathsf { m a x } } )$ 也曾觀察到五倍的差異。然而，儘管血液濃度有差異，但男性和女性之間卻沒有藥效學上的差異。

## 老年

已知褪黑激素代謝會隨年齡而下降。在固定的劑量範圍，發現與年輕受試者相比，老年受試者的AUC和 $C _ { \mathsf { m a x } }$ 數值較高，反映了老年人褪黑激素的代謝率較低。成人（18-45歲）的 $c _ { \mathsf { m a x } } ]$ 大約為500 pg/mL水平與老年人的 $C _ { \mathsf { m a x } }$ 大約為1200 pg/mL（55-65）；成人的AUC約在3000 $p g ^ { \star } h / m L$ ，而老年人的AUC約為6000 pg\*h/mL。

## 12 臨床試驗資料

臨床試驗第三期研究和睡眠實驗室研究被視為樞紐試驗。這些研究納入了年齡⼤於55歲的原發性失眠病⼈。不包含患有嚴重神經系統疾病，精神病或神經外科疾病或服⽤中樞神經治療藥物（包括苯⼆氮卓類藥物或其他安眠藥物）的病⼈。主要評估⼯具是李⽒睡眠評質量表（LSEQ），其中包括 10 個關於睡眠和清晨⾏為⽅⾯的⾃評問題。 LSEQ 測量入睡容易程度（GTS），睡眠品質（QOS），睡眠清醒容易度（AFS）和清醒後⾏為（BFW）。臨床樞紐試驗的最主要的療效指標是睡眠品質，或是睡眠品質和清醒後⾏為的組合（病⼈必須在睡眠品質以及清醒後⾏為有臨床上的改善）。僅在多導極睡眠監測研究中客觀觀察入睡時間和睡眠⻑度。Circadin與其他催眠藥合併使⽤的療效尚未評估。

在多導極睡眠檢查（PSG）研究（受試40位；Circadin和安慰劑組各半）中，開始2週的單盲與安慰劑治療，接著治療3週（雙盲、安慰劑對照組、平行試驗）和3週的退出期。使用Circadin的受試者入睡的時間比安慰劑組明顯縮短了9分鐘。經試驗發現Circadin對於入睡時間的改善較安慰劑組有顯著差異（Circadin組為10至11分鐘，安慰劑組為21至20分鐘）。在本試驗中也發現，Circadin對睡眠結構和快速動眼睡眠期間並沒有影響。與安慰劑組相比，Circadin不會影響日夜周期也不會延長睡眠持續時間。

第二個針對門診病人的試驗（共334位受試者；Circadin組169位，安慰劑組165位），前2週使用安慰劑，隨後3週採隨機，雙盲，安慰劑對照組，平行比較方式，治療3週。發現受試者在睡眠品質和晨間清醒度有臨床上明顯地改善的比例，Circadin治療組為26%，而安慰劑治療組為15%。Circadin治療組病人紀錄想睡到睡著的時間縮短了24.3分鐘，而安慰劑治療組縮短了12.9分鐘。此外，病人自評其睡眠質量，覺醒次數和晨間清醒度，Circadin治療組明顯比安慰劑治療組改善更多。Circadin治療組生活品質的改善也比安慰劑對照組明顯。

第三項研究的55歲以上受試者超過600名，其中400多名病⼈使⽤Circadin治療⻑達6個⽉。給予Circadin的病⼈在使⽤睡眠⽇記評估主觀入睡時間變化，與安慰劑組相比在3週後相差7.8分鐘（p=0.014），13週內，治療組與安慰劑對照組相比，總是維持入睡時間縮短的⼩差異。此外，試驗結果顯⽰失眠緩解（PSQI<6）和臨床相關的⽣活品質評量提⾼10%(WHO-5 指數)的病⼈占比從第3週的16.7%（安慰劑組為10.6%，p=0.044）增加⾄第13週時的 25.8%（安慰劑組為15.7%安慰劑，p=0.006）。

本研究還檢測了Circadin對年輕⼈原發性失眠和褪⿊激素代謝產物低的受試者縮短入睡時間的影響。未發現對入睡時間縮短有臨床上的顯著意義。

⻑期的安全性:3週和26週期間的安全性與安慰劑組相當，沒有戒斷和反彈性失眠。在⼀項非盲⻑期試驗中，96名受試者完成12個⽉的Circadin治療，沒有發現耐受性、反彈性失眠或戒斷現象。
