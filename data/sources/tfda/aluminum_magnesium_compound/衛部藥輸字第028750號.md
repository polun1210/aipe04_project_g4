# 日方藥研胃腸藥顆粒KAKONAMIN ICHOYAKU GRANULES

衛部藥輸字 第 028750 號

醫師藥師藥劑生指示藥品

版本 日 期 2024-10-18

日方藥研胃腸藥顆粒是配合促進消化的消化酵素、中和胃酸的制酸劑、健胃生藥等的綜合胃腸藥。2種制酸劑中和胃酸、改善胃痛等的症状。另含5種健胃生藥。東莨菪萃取末抑制胃液分泌、緩解胃痛。

## 1.2 其他成分(賦形劑)

Potato Starch, Lactose Hydrate, Hydroxypropylcellulose, Carmellose Calcium, l-Menthol

## 2 用途(適應症)

緩解胃部不適或灼熱感、或經診斷為胃及十二指腸潰瘍、胃炎、食道炎所伴隨之胃酸過多、食慾不振、胃腹部膨脹感、消化不良、幫助消化

3 使用上注意事項

3.1 有下列情形者，請勿使用

3.1.1) 曾因本藥成分引起過敏的人

3.1.2) 哺乳婦請勿服用本藥，若服用本藥時請避免哺乳。因為服用本藥而哺乳的婦女，受哺乳的嬰兒會有心跳加速的情況發生

3.2 有下列情形者，使用前請洽醫師診治

3.2.1) 3歲以下

3.2.2) 消化道潰瘍的人

3.2.3) 有腎臟疾病的人

3.2.4) 須限鹽飲食的人

3.2.5) 有高血壓、心臟病、腎疾、腹水、水腫、青光眼的人

3.2.6) 腎衰竭病患(長期服用含鋁胃藥可能導致或加重透析治療引起之透析性骨軟化症、透析性腦病變及低磷血症，應謹小心使用)

3.3 有下列情形者，使用前請先諮詢醫師藥師藥劑生

3.3.1) 孕婦、可能懷孕婦女及哺乳婦

3.3.2) 65歲以上或有排尿困難的人

3.3.3) 與其他藥品併用時

3.4 其他使用上注意事項

3.4.1) 為防止兒童誤食請妥善保管

3.4.2) 避免陽光直射

3.4.3) 勿超過建議使用量

3.4.4) 一天內不可服用超過一日最大使用量，也不可連續服用一日最大使用量兩週以上

3.4.5) 如長期與鈣質牛奶併用，會引起高血鈣、腎衰竭、鹼中毒、噁心、嘔吐、頭痛、意識不清、厭食等現象

## 5 警語

5.1 服用本藥後，若有發生以下副作用，請立即停止使用，並持此說明書諮詢醫師藥師藥劑生

| 身體部位 | 副作用 |
| --- | --- |
| 胃腸道 | 便祕、噁心、嘔吐、腹瀉 |
| 皮膚 | 發疹、發紅或發癢 |
| 其他 | 偶有過敏、口乾、口渴 |

5.2 服用本藥後，若有發生以下症狀時，請立即停止使用，並接受醫師診治

5.2.1) 若有任何不適情況產生

5.2.2) 連續服用本藥數日後，若症狀沒有改善
