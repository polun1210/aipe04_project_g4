# 交互作用規則可引用少量非目標營養素成分

> 設計決策的參考紀錄，不是硬性規定；想調整請見 [README](README.md)。

目標營養素（13 項）的篩選條件是「在 DRIs 第八版總表中有可用的數值基準」（ADR-0002），
因為它們要做定量判定。但交互作用判定只問「有沒有」，不涉及任何數值，
而民眾實際大量補充、與慢性病處方藥關係最危險的幾種成分，恰好落在 13 項之外——
紅麴的 monacolin K 化學上就是 lovastatin，民眾卻不認為紅麴是藥。

我們決定**交互作用規則可以引用非目標營養素的標示成分**，但以少量、高證據為限。
這不違反 ADR-0002：ADR-0002 限制的是「定量判定的錨」，交互作用規則不使用 DRIs 數值。
也不需要新的辨識工作：營養標示模組本來就辨識全部標示成分（見 `docs/schemas/supplement-label-output.md`）。

## Consequences

- **第一版允許清單為 3 項**：紅麴（× Statin → 重複用藥）、葡萄糖胺（處方 vs 市售 → 重複補充）、
  魚油 n-3（× COX-2 → 出血加成，待驗證）。清單見 `docs/v1-scope-checklist.md` §3。
- 納入條件：至少一條交互作用能通過建表規範，且該成分在台灣市售保健食品中常見。
  為了湊數或「看起來完整」而納入的，不符合條件。
- 這些成分**只參與交互作用與重複補充判定**，不因此成為目標營養素，不做劑量判定、不比對上限，
  在 schema 中列於 `ALLOWED_INGREDIENTS`（`enums.py`），成分目錄的 `category` 為 `allowed_ingredient`。
- 這三項成分通常**不在營養標示方框內，而在成分欄**，辨識範圍必須涵蓋成分欄。
- 每一項允許成分都需要一個標準代碼與同義詞對映（例如紅麴 ／ Monascus ／ red yeast rice），
  由營養標示模組的名稱標準化一併維護。
- 清單以外的非目標成分（Q10、益生菌、膠原蛋白等）如實辨識但不做評估（`scope_status = out_of_scope`）。
