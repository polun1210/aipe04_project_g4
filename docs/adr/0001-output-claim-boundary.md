# 系統輸出的宣稱邊界：呈現數值，不給劑量指示

> 設計決策的參考紀錄，不是硬性規定；想調整請見 [README](README.md)。

本系統的 TA 是一般民眾，輸出涉及用藥交互作用與補充品增減，若給出具體劑量等同處方行為。
我們決定系統只呈現三個客觀數值——來自補充劑的攝取量、建議總攝取量、上限攝取量——
以及超過上限可能產生的風險說明與方向性建議（例如「你重複補充 X，可留意 Y 方面」），
並在任何情況下**不輸出建議劑量數字、不建議停用特定保健食品、不建議購買特定商品**。

## Consequences

- 這條邊界在 **output schema 層** 執行，而非倚賴 prompt 約束：判定結果是封閉列舉
  （相關營養素／接近上限／交互作用），schema 中不存在可以填入建議劑量的欄位，
  LLM 因此無處可放這類內容。
- **不提示不足**：在沒有飲食資料時，不足在數學上無法計算。「相關營養素」只列出三個數值與關聯說明，不判定高低。
- Evaluation 需新增一項硬性檢查：報告敘述中出現的所有數字，必須全部能對應到同一區塊的
  結構化數值欄位，否則判定為幻覺。
- 報告中並列「補充劑來源攝取量」與「建議總攝取量」時，欄位名稱必須標明兩者計算範圍不同，
  否則等同暗示使用者攝取不足（見 CONTEXT.md 對兩詞的定義）。
- 使用者若需要知道該補多少，系統的回應是引導其尋求醫師、藥師或營養師，而非自行給出數字。
