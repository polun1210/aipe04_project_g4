# 多條規則命中同一成分時取最高等級，永不降級

> 設計決策的參考紀錄，不是硬性規定；想調整請見 [README](README.md)。

規則表採單條件模型（見 `docs/schemas/rule-table.md`）：每條規則只綁一個條件，
組合在執行期按成分聚合，需要一個明確的聚合規則。

我們決定：**同一成分被多條規則命中時，顯示其中最高的等級，並列出所有觸發來源；任何資料都不能降低警示。**

拒絕「可升可降」的理由：降級等於用某一筆資料否定另一筆資料觸發的警示，
而且每一種降級條件都需要出處，系統無從保證降級是安全的。
升級則不需要額外規則：取最高等級本身就讓多重風險浮現。

## Consequences

- 聚合是純函數：`max(severity)`，加上觸發規則清單。不需要建表，不需要人判斷。
- 報告中同一成分只出現一次，列出所有觸發它的條件
  （例如鎂：「因為你正在服用 PPI 與 Thiazide 類利尿劑」）。
- `requires_professional_review` 採 OR：任一條命中規則為真，該成分即為真。
- 真正「效果不是各自相加」的組合，以一條獨立規則表達，不在聚合邏輯中處理。
- 聚合邏輯的正確性以單元測試驗證。
