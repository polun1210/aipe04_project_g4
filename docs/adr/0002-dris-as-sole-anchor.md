# DRIs 第八版為唯一營養標準錨

> 設計決策的參考紀錄，不是硬性規定；想調整請見 [README](README.md)。

系統的所有定量判定，僅採用《國人膳食營養素參考攝取量》第八版總表作為基準；
一個營養素要成為目標營養素，必須在該總表中有可用的數值，此為硬性條件，不開例外。
替代方案是為 DRIs 未涵蓋的成分各自引入外部標準（EFSA、IOM、AREDS2 等），
我們拒絕這條路，因為第二套錨會連帶要求 provenance 欄位、標準間的優先順序規則與衝突處理，
且一旦開了先例，Q10、益生菌等成分會持續要求例外。

## Consequences

- **允許成分不做定量判定。** 紅麴、葡萄糖胺、魚油 n-3 不在 DRIs 總表中（n-3 只有佔總熱量比例的 AMDR，
  沒有補充劑劑量建議值與上限），只參與交互作用與重複補充判定（ADR-0007）。
- Q10、益生菌、薑黃、膠原蛋白等 DRIs 外成分如實辨識並保留，但不做評估（`scope_status = out_of_scope`）。
- **上限攝取量的來源定義並不一致**，呈現時必須分別處理：鎂與鐵的上限在 DRIs 原文中
  已限定僅計算補充劑與強化食品來源（原文註腳「† 為非食物性鎂量」、
  「‡ 此量不包括非強化飲食之鐵含量，只適用於強化食品與補充劑等之總鐵量」），
  其餘營養素的上限則為含飲食的總攝取量。
- DRIs「以健康人為對象」（本文序），上限攝取量的定義為「對健康族群中絕大多數人都不致引發危害風險」。
  使用者勾選任一慢性病時，報告須揭露參考值適用於健康族群（見 `docs/dris-reference-notes.md`）。
  報告中的數值錨只有 DRIs 一套，不引入任何疾病專屬的數字。
