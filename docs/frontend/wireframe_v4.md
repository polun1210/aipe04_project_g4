# 網站 Wireframe（黑白線框規劃稿）

> 依據 `wireframe文字敘述_v4.txt` 整理。此文件只規劃頁面結構、內容順序、元件狀態與跳轉，不代表完成的視覺設計。線框中的資料與日期均為示意。
>
> 圖例：`[按鈕]`、`[________]` 輸入框、`[選項 ▼]` 下拉選單、`☐` 核取方塊、`(圖片區)` 圖片預覽、`[停用]` 不可點擊。建議使用支援等寬字體的 Markdown 檢視器閱讀。

## 一、頁面與主要操作順序

```text
主頁 ─┬─ 註冊頁 ── 主頁
      ├─ 登入頁 ── 主頁（已登入）
      ├─ 會員中心 ─┬─ 設定頁 ── 會員中心
      │             ├─ 報告記錄查詢 ── 報告記錄詳細資料
      │             └─ 登出 ── 主頁
      └─ 開始使用
            ↓
       藥圖片上傳 ── 辨識失敗 → 重新上傳
            │
       辨識成功 → 還有其他藥包？ ── 有 → 清空本頁、再次上傳
            │ 沒有
            ↓
       藥人工校對（全部勾選確認後）
            ↓
       保健食品圖片上傳 ── 辨識失敗 → 重新上傳
            │
       辨識成功 → 還有其他保健食品？ ── 有 → 清空本頁、再次上傳
            │ 沒有
            ↓
       保健食品人工校對 + 實際服用方式
            ↓
       報告呈現 ── 回主頁／下載 PDF
```

### 07｜藥人工校對頁

**預設：左圖右資料**

```text
┌────────────────────────────────────────────────────────────────────┐
│                          藥人工校對                                │
├─────────────────────────────┬──────────────────────────────────────┤
│                             │ 請確認資料是否正確                   │
│  ┌───────────────────────┐  │                                      │
│  │                       │  │ 藥名 A     [編輯]  ☐ 鎖定變更       │
│  │     上傳圖片預覽      │  │ 藥名 B     [編輯]  ☑ 鎖定變更       │
│  │                       │  │                    （編輯停用）      │
│  └───────────────────────┘  │                        [＋新增]      │
│                             │                                      │
│                             │ [         下一步         ]          │
└─────────────────────────────┴──────────────────────────────────────┘
```

**按下某筆「編輯」後（只示意右側該筆）**

```text
│ 藥名                                                        │
│ [輸入正確藥名________________]                               │
│  提示詞／候選藥名：[候選 1] [候選 2]                        │
│                        [儲存] [取消]                         │
```

**新增一筆**：點 `[＋新增]` 直接出現上述編輯狀態，但藥名預設為空白；若空白儲存或取消新增，則移除該筆。

**未全部確認時**：

```text
│ 有未確認項目，麻煩請再檢查一次！                            │
│ [下一步（無法跳轉）]                                        │
```

- 勾選「鎖定變更」後該筆編輯按鈕停用；所有項目勾選後才能按下一步。
- 儲存：顯示修改後藥名；取消：保留原藥名，回預設狀態。
- 下一步 → 保健食品圖片上傳頁。

### 09｜保健食品人工校對頁

**預設：左側圖片，右側辨識結果與服用方式**

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        保健食品人工校對                                │
├──────────────────────────┬─────────────────────────────────────────────┤
│                          │ 營養素名     每份劑量 單位                 │
│ ┌──────────────────────┐ │ 維生素 C     100      mg   [編輯] ☐ 鎖定  │
│ │  成分表／營養標示    │ │ 鈣           200      mg   [編輯] ☑ 鎖定  │
│ │  上傳圖片預覽        │ │                           （編輯停用）    │
│ └──────────────────────┘ │                              [＋新增]       │
│                          │ ─────────────────────────────────────────── │
│                          │ 使用者實際服用方式                          │
│                          │ 服用頻率  [請選擇 ▼]                        │
│                          │ 每日次數  [請選擇 ▼]                        │
│                          │ 每次服用量[請選擇 ▼]                        │
│                          │                                             │
│                          │ [            下一步             ]         │
└──────────────────────────┴─────────────────────────────────────────────┘
```

**編輯單筆營養素**

```text
│ 營養素名稱     [請選擇營養素 ▼]                             │
│ 每份劑量       [___________]  （只能輸入數字，不顯示提示詞） │
│ 劑量單位       [請選擇單位 ▼]  （例如 ug、mg、g）           │
│                       [儲存] [取消]                         │
```

- 編輯時隱藏該筆的「編輯」及「鎖定變更」，改顯示「儲存／取消」。
- 儲存後呈現修改值；取消後還原原值。新增時直接進入空白編輯狀態；營養素名稱空白時儲存或取消，直接刪除新增項。
- 單位表示以 `ug` 取代 `μg`（依原文指定的 `app/schemas/enums.py` 慣例）。

**服用頻率：條件式欄位**

```text
│ 服用頻率 [每天／每兩天／每周指定天數／週期性服用停用 ▼]     │
│                                                              │
│ 若選「每周指定天數」：                                      │
│   每周服用幾天 [________]（days_per_week）                   │
│                                                              │
│ 若選「週期性服用／停用」：                                  │
│   連續服用天數 [_______]（cycle_on_days，> 0）              │
│   停止服用天數 [_______]（cycle_off_days，> 0）             │
```

**三個下拉選單的內容**

| 欄位 | 選項或規則 |
|---|---|
| 服用頻率 `frequency_type` | 每天 `daily`、每兩天 `alternate_days`、每周指定天數 `weekly_n_times`、週期性服用／停用 `cyclic_on_off` |
| 每日次數 `times_per_day` | 1 次、2 次、3 次 |
| 每次服用量 `amount_per_time` | 依保健食品劑型／DoseUnit 動態變更（見下表） |

| 劑型（依原始敘述） | 每次服用量選項 |
|---|---|
| 錠劑（原文標示 `capsule`） | 1、2、3、4、5 錠 |
| 膠囊（原文標示 `tablet`） | 1、2、3、4、5 顆 |
| 軟膠囊 `softgel` | 1、2、3、4、5 顆 |
| 軟糖 `gummy` | 1、2、3、4、5 顆 |
| 包／小包裝 `sachet` | 1、2、3、4、5 包 |
| 量匙 `scoop` | 1、2、3、4、5 匙 |
| 滴劑（原文標示 `ml`） | 1、2、3、4、5、10、15、20 滴 |
| 液體（原文標示 `drop`） | 1、2、5、10、15、20、30 mL |
| 粉末／重量 `g` | 1、2、3、5、10、15、20 g |

> **待確認（保留原文）**：原始 txt 的 `capsule/tablet` 與 `ml/drop` 英文代碼和中文劑型可能對調；此處不自行修改專案列舉值，開發前請核對 `app/schemas/enums.py`。

**驗證狀態**：若任何營養素未勾選「鎖定變更」，或服用方式有必填欄位未填，顯示：

```text
│ 有未確認項目，麻煩請再檢查一次！                            │
│ [下一步（無法跳轉）]                                        │
```

- 符合條件後，下一步 → 報告呈現頁。
