## PG-001 首頁

### 頁面目的

網站主頁面，讓使用者了解系統功能並開始使用。

### Wireframe

```
┌─────────────────────────────────────────────────────┐
│ Logo（專案名稱）                    註冊    登入      │
├─────────────────────────────────────────────────────┤
│                                                     │
│                    歡迎使用                         │
│                                                     │
│                  [ 開始使用 ]                        │
│                                                     │

│                                                     │
│                使用指南                             │
│                                                     │

- 導覽列
    - 左側：Logo／專案名稱
    - 右側：註冊
    - 右側：登入
- 歡迎畫面
- 開始使用按鍵
- 系統相關介紹
- 使用指南

```
┌─────────────────────────────────────────────────────┐
│ Logo（專案名稱）                  會員中心    登出     │
└─────────────────────────────────────────────────────┘

### 頁面內容

#### 標題

「請確認保健食品資訊」

#### 左側

- 使用者上傳的圖片
- 辨識項目／指標
- 顯示辨識了哪些資訊

#### 右側：AI 辨識結果

使用者可以確認並修改 AI 辨識結果。

### 使用者可修改項目

| 修改項目 | 建議 HTML 標籤 | 使用者可修改內容 |
| --- | --- | --- |
| **成分名稱** | `<select>` 下拉選單 | 從系統提供的標準成分中選擇，例如：維生素D、維生素B12、維生素C、鈣、鎂、鋅⋯ |
| **每份數量** | `<input type="number">` | 例如：1、2、3 |
| **每份單位** | `<select>` | 例如：粒、錠、顆、包、毫升、克⋯ |
| **營養／成分數值** | `<input type="number">` | 例如：200 mg、10 µg、2.5 g 等數值 |
| **成分單位** | `<select>` | 例如：mg、µg、g、mL 等系統允許的單位 |
| **漏辨識的成分** | `<select>` + `<input>` | 從標準成分選擇後，補上 AI 漏掉的成分及數值 |
| **誤辨識的成分** | 刪除按鈕 `<button>` | 將 AI 多辨識出的成分刪除 |

### 實際服用方式

在同一頁提供使用者確認實際服用方式，不另外建立 PG-008。

| 輸入項目 | 建議 HTML 標籤 | 使用者可修改內容 |
| --- | --- | --- |
| **服用頻率** | `<select>` | 每天、每兩天、每週幾次、週期服用、需要時服用等 |
| **每日次數** | `<select>` | 1 次、2 次、3 次 |
| **每次服用量** | `<select>` | 依保健食品劑型動態顯示對應選項 |

### 單次服用量

單次服用量依照保健食品劑型動態顯示。

| 專案 DoseUnit | 前端顯示 | 建議選項 |
| --- | --- | --- |
| `tablet` | 錠 | 1～5 錠 |
| `capsule` | 顆 | 1～5 顆 |
| `softgel` | 顆 | 1～5 顆 |
| `gummy` | 顆 | 1～5 顆 |
| `sachet` | 包 | 1～5 包 |
| `scoop` | 匙 | 1～5 匙 |
| `drop` | 滴 | 1、2、3、5、10、15、20 滴 |
| `ml` | mL | 1、2、5、10、15、20、30 mL |
| `g` | g | 1、2、3、5、10、15、20 g |

# 5. Wireframe 階段的設計原則

目前 Wireframe 主要確認：

1. 每個頁面需要放哪些內容
2. 使用者操作的先後順序
3. 頁面之間如何跳轉
4. 哪些功能需要登入
5. 使用者可以修改哪些 AI 辨識結果
6. 不同保健食品劑型對應的服用量選項
7. 使用者可以查看過去的健康分析報告
8. 使用者可以從報告記錄查詢頁進入指定報告的詳細資料

目前**不處理**：

- 最終配色
- 字體
- 圖示風格
- 按鈕詳細視覺樣式
- 動畫
- RWD 細節
- 最終 UI 元件樣式

這些內容可在 Wireframe 確認後，再進入 UI/UX 設計階段。
