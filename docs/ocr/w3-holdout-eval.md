# W3 保留集初步驗收

保留集是**沒有拿來調過辨識規則**的 20 張保健食品標示照片，用來檢查辨識在新照片上的表現（對應老師 W3「20 張保留照片逐欄核對」）。

## 照片

| 來源 | 張數 | 說明 |
|---|---|---|
| 手機自拍 | 2 | p04、p06（曲面瓶身、字很小、成分欄被切） |
| 網路商品圖 | 18 | p13–p30，大多是 PChome 商品圖，另有品牌官網與部落格 |

類別分散：魚油、葡萄糖胺、鈣鎂、鐵、綜合維生素、B 群、維生素 C、紅麴等。照片有版權，只留在各自電腦的 `data/images/`，
來源網址記在 `tests/fixtures/labels/sources.csv`（`dataset=holdout`）。

## 標準答案怎麼來的

同比較集的流程：

1. Claude（claude-opus-5-5）與 Codex（gpt-6.1-sol）各自只看一張照片標註，彼此看不到對方的結果
2. 逐欄比對：已配對欄位一致 99.8%；單位 κ 1.00、所在區塊 κ 0.99；每份含量、%DV、每一份量 100% 一致
3. 37 處不一致逐張對照原圖裁決（34 處是成分欄的賦形劑、乳酸菌、色素，都在範圍外）
4. 一致的部分人工抽查 20 格（每張 1 格，只抽會影響計算的欄位），全對
5. 結果在 `tests/fixtures/gold_holdout/`

## 結果

辨識：Gemini 3.8 Flash（經 OpenRouter）＋規則層，錄製結果在 `tests/fixtures/engine_responses/openrouter/`。

```bash
uv run python scripts/eval_drafts.py --gold tests/fixtures/gold_holdout
```

| 指標 | 結果 |
|---|---|
| 逐欄正確（範圍、代碼、數值、單位都對） | **91%**（307／338） |
| 範圍內成分（會進評估的）找到 | 98%（90／92），數值、單位、型態全對 97%（89／92） |
| 漏抓／多抓 | 3%／1% |
| 每一份量 | 90%（18／20） |

## 錯誤在哪裡

- **大多數是目錄沒有的名稱**：碘、磷、鉻、硼、膠原蛋白、穀胱甘肽等不在 13 項目標營養素裡，目錄也沒有，
  草稿標成「無法判定」請使用者確認（答案是範圍外）。方向安全，只是多要使用者確認幾列
- **真的會漏掉的 3 個**：
  - p29 紅麴：漏抓「Monacolin K 12±2.4 毫克」這一列
  - p13 紅麴：Monacolin K 有抓到，但含量是空的（答案 3 毫克）
  - p19：「葡萄糖胺-鹽酸鹽」中間有連字號，對不到目錄，變成無法判定
- p06 成分欄左側被切掉，幾個乳酸菌名稱沒抓到（範圍外）
- 附註：p18 的標示本身印成「維生素C 10毫克 α-TE (15IU)」，但 α-TE、IU 是維生素 E 的單位、成分欄也有維生素 E。
  標準答案照「標示上寫了什麼」記成維生素 C，沒有替廠商更正；這種標示錯誤要靠使用者在核對畫面修正

## 限制

- 自拍只有 2 張，網路圖大多是乾淨的數位圖，所以這個數字比實際用手機拍的情況樂觀
- 保留集不能拿來調規則；之後的改進只能做通用的修正，再用同一批照片比較改善多少，報告會寫明
- 影像品質檢查的短邊門檻參考過 p20（長條形的網路圖）；這是品質檢查的門檻，不是辨識規則
